# Página de Futebol ⚽

## Descrição
Página web simples sobre futebol, com informação sobre o desporto e os meus clubes favoritos.
Projeto feito para a UC00617 – Utilizar serviços Git e GitHub.

## Como usar
1. Carregar no botão verde **Code** e escolher **Download ZIP** (ou clonar com o GitHub Desktop).
2. Extrair a pasta.
3. Abrir o ficheiro `index.html` num browser (Chrome, Edge, etc.).

## Funcionalidades
- Menu de navegação
- Rodapé com o nome do autor
